# AWS architecture icons

These SVGs are the official AWS Architecture Icons, used to label components in
the System Design Studio (`/design`). Each file is named after the generic
component type it represents (see `lib/design/catalog.ts` → `AWS_SERVICE`).

Sourced from the `aws-icons` package (MIT License, © 2023 Mohammad Abu Mattar),
which repackages the AWS Architecture Icon set. AWS icons are provided by Amazon
